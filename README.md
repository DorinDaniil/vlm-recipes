# vlm-recipes

Дообучение открытой LLM под продуктовую задачу: ассистент студента,
пишущего выпускную работу в редакторе. Модель должна выбрать навык
вызовом `select_skill`, а затем ответить по правилам продукта:
содержательные решения оставлять студенту, не помогать обходить
проверки и не выдумывать данные, правки формы предлагать к принятию,
опираться только на открытый документ, заканчивать одним шагом.

Методы: SFT (LoRA), выравнивание на парах (DPO, ORPO, SimPO, KTO),
вектор управления. Модель в примерах — Qwen3.5-9B; код к семейству
не привязан.

## Структура

    books/        теория, PDF; исходники в books/tex
    notebooks/    эксперименты, один метод на ноутбук
    data/         голд-сет продукта, трейн-сет, навыки, документы
    tools/        проверка модели, данных, окружения
    docs/         бенчмарки
    vlmkit/       коллатор, генерация, навыки, автопроверки по рубрикам, совместимость версий

## Установка

    pip install -r requirements.txt

`torch` устанавливается отдельно под версию CUDA, поддерживаемую
драйвером. Проверка модели и данных:

    python tools/check_model.py Qwen/Qwen3.5-9B
    python tools/selfcheck.py

## Данные

**Тест-сет** — голд-сет команды продукта, `data/golden.jsonl`:
36 ситуаций в шести категориях (рецензия и правки текста, литература,
методы и эмпирика, маршрут работы, замечания руководителя, элементы
введения). У каждой — запрос студента, открытый фрагмент документа,
рубрика PASS/FAIL из трёх пунктов, ответ продового агента с вердиктами
LLM-судьи и человека, а также авторский эталонный ответ и заведомо
плохой. Исходная таблица — `data/source/golden_set_feedback.xlsx`,
сборка — `data/build_golden.py`.

**Трейн-сет** — `data/train/*.jsonl`, 76 ситуаций тех же типов на
других работах (педагогика, ИТ, экономика, экология, лингвистика),
чтобы тексты документов не пересекались с тестом. Поля: запрос,
документ, ожидаемый навык, эталонный ответ, плохой ответ, назначенные
автопроверки.

`data/skills.json` — шесть навыков: текст методики, который получает
модель после `select_skill`. `data/documents.json` — фрагменты
документов.

## Метрики

Все на голд-сете, формулы и разбор — в `00-data`.

| метрика | что считает |
|---|---|
| skill_acc | верный навык в вызове `select_skill`, точное имя |
| completed | цикл завершился ответом, а не повторным вызовом |
| checks_all | выполнены все автопроверки рубрики: заземлённость в документе, не анкета, один шаг, есть альтернатива при отказе, не переписывает, обязательные подстроки |
| refusal recall / FPR | отказ там, где он нужен, и в начале ответа там, где не нужен |
| judge_pass | вердикт LLM-судьи по рубрике голд-сета; согласие с вердиктами команды измеряется отдельно |
| perplexity, preference accuracy | вероятность эталонов и пар на отложенных ситуациях |

Автопроверки — `vlmkit/rubric.py`, стандартная библиотека; проверены
на эталонах (100 %) и плохих ответах (3 %).

## Ноутбуки

| | что делает |
|---|---|
| `00-data` | голд-сет с полными примерами, вердикты продукта, метрики с формулами, судья против человека, базовая линия модели |
| `01-sft` | LoRA на траекториях «запрос → select_skill → навык → ответ»; до/после на голд-сете, полные ответы |
| `02-steering` | вектор «отказ с альтернативой» из пар эталон/плохой; развёртка по силе; recall / FPR отказов |
| `03-dpo` | ORPO / DPO / SimPO / KTO на парах, при желании поверх SFT-адаптера; preference accuracy |
| `04-compare` | все сохранённые варианты на голд-сете в одной таблице, ответы рядом |
| `05-chat` | свои запросы с документом к любому варианту; полный промпт, потоковый ответ |

Вызовы `peft`, `transformers`, `trl` в ячейках без обёрток.

## vlmkit

- `data` — `Sample`, `ChatCollator` (маскирует промпт, описание и
  результаты инструментов, блок `<think>`), `preview`
- `evaluate` — генерация с left padding и выключенным рассуждением,
  `Suite` с матрицей ошибок, `perplexity`, `preference_accuracy`
- `skills` — схема `select_skill` и подстановка текста навыка
- `rubric` — автопроверки ответа по рубрикам
- `toolcalls` — разбор `<tool_call>` в JSON и XML
- `steering` — `SteeringVector`
- `compat` — фильтр аргументов, поиск тренеров TRL по версии
- `model`, `chat`, `guardrails` — загрузка, диалог, фильтрация запросов
